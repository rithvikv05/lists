# Lists - Design System & Architecture

Lists is an open-source, content-first media catalog and tracking application built with **Material Design 3 (M3) Bare Minimalism**. It features a unified, refined architectural ledger that scales cleanly across Android and Web.

---

## 1. Core Principles

1. **Bare Minimalism**: No decorative gradients, no chunky bubble cards, no skeuomorphic drop shadows, and no superfluous marketing copy. Every design element serves an immediate functional purpose.
2. **Dual-Tone High Contrast**:
   - **AMOLED Dark Mode**: Pure `#000000` pitch black background, `#0C0C0D` low-glare surface cards, `#222427` hairline borders, and pure `#FFFFFF` crisp primary typography.
   - **Paper Light Mode**: Pristine `#FAFAFA` warm paper background, `#FFFFFF` crisp surfaces, `#E4E4E7` borders, and high-contrast `#09090B` typography.
3. **Semantic Category Accents**:
   - Accents are functional identifiers.
   - **Movies**: Coral Red (`#EF5350`)
   - **TV Shows**: Violet (`#AB47BC`)
   - **Books**: Sage Emerald (`#26A69A`)
   - **Games**: Sky Blue (`#42A5F5`)
   - **Comics / Manga / Anime / Board Games**: Distinct designated palette tokens.
4. **Platform Parity**:
   - Shared reactive models, data flow, responsive adaptive layout, discrete ratings, segmented buttons, and cloud synchronization across Android and Web.
